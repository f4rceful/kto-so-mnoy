# Настройка

Настройки сервиса хранятся в файле `.env` в корне проекта. Как создать и открыть этот файл, написано в инструкции
для вашей системы: [Windows](windows.md#4-скачивание-и-настройка), [macOS](macos.md#4-скачивание-и-настройка),
[Linux](linux.md#4-скачивание-и-настройка).

## Бот на платформе MAX

1. Откройте [платформу партнёров MAX](https://business.max.ru/self), раздел "Чат-боты", и создайте бота.
2. Из карточки бота возьмите **токен** (`BOT_TOKEN`) и **имя** без `@` (`BOT_USERNAME`). Имя нужно для ссылки
   `https://max.ru/<имя>?startapp`, которой открывается мини-приложение.
3. Чтобы мини-приложение открывалось из чата с ботом, укажите его адрес в настройках бота: "Чат-боты" → меню бота (⋮) →
   "Настройки" → "Мини-приложение". Адрес только `https://`. Эти настройки доступны после модерации бота, а любое
   изменение отправляет бота на повторную проверку.

## Переменные в `.env`

Обязательны токен и имя бота, а для запуска в Docker ещё пароль базы.

| Переменная | Обязательна | Значение |
| --- | --- | --- |
| `BOT_TOKEN` | да | токен бота с платформы партнёров MAX |
| `BOT_USERNAME` | да | имя бота без `@` |
| `ADMIN_KEY` | нет | ключ панели модератора `/admin`; пусто - панель выключена |
| `POSTGRES_PASSWORD` | для Docker | пароль базы в контейнере `db` |
| `DATABASE_URL` | без Docker | строка подключения, например `postgresql+psycopg://kto:пароль@localhost:5432/kto_so_mnoy` |
| `PUBLIC_URL` | нет | публичный HTTPS-адрес, например `https://kto.example.ru`; задан - бот получает события через webhook, пусто — через long polling |
| `WEBHOOK_SECRET` | нет | секрет webhook (5–256 символов: латиница, цифры, `-`, `_`); пусто - выводится из токена |
| `DEV_MODE` | нет | `true` - вход без MAX по адресу `http://localhost:8000/?dev=1`, только для разработки |
| `BOT_QUICK_ACTIONS` | нет | `true` - кнопки "Принять / Отклонить" прямо в чате с ботом |
| `METRICS_TOKEN` | для мониторинга | токен доступа к `/metrics` (длинная случайная строка); пусто - метрики выключены |
| `GRAFANA_PASSWORD` | для мониторинга | пароль администратора Grafana (логин `admin`); не задан - `admin` |
| `GRAFANA_PORT`, `PROMETHEUS_PORT`, `ALERTMANAGER_PORT` | нет | порты на вашем компьютере, по умолчанию `3000`, `9090` и `9093` |
| `ALERT_USER_IDS` | нет | номера пользователей MAX, которым бот пишет об авариях; пусто - оповещения выключены |
| `GRAFANA_URL` | нет | адрес Grafana для кнопки "Графики" в панели модератора |
| `APP_VERSION` | нет | версия, которую сервис показывает в метриках; по умолчанию `dev` |

## Случайные ключи и токены

`ADMIN_KEY`, `METRICS_TOKEN`, `WEBHOOK_SECRET` и пароли должны быть длинными и случайными. Получить такую строку (48 символов):

macOS и Linux:

```bash
openssl rand -hex 24
```

Windows (PowerShell):

```powershell
$b = New-Object byte[] 24; (New-Object Security.Cryptography.RNGCryptoServiceProvider).GetBytes($b); -join ($b | ForEach-Object { '{0:x2}' -f $_ })
```

## Публичный адрес и webhook

Мини-приложение открывается из MAX только по публичному адресу с HTTPS. Этот адрес записывается в `PUBLIC_URL`.

- **Пока `PUBLIC_URL` пуст**, бот получает события сам, через long polling. Подходит для проверки на своём компьютере.
- **Когда `PUBLIC_URL` задан**, сервис при запуске подписывает бота на webhook по этому адресу, а MAX сам присылает события.
- **Для проверки с телефона** без своего домена подойдёт туннель, например [ngrok](https://ngrok.com/): `ngrok http 8000`,
  а выданный адрес вписать в `PUBLIC_URL` и в настройки мини-приложения бота. Бесплатный адрес ngrok меняется при каждом запуске,
  а любая смена адреса в настройках бота отправляет его на повторную модерацию.
- **Для постоянной работы** поставьте перед сервисом обратный прокси с HTTPS, например [Caddy](https://caddyserver.com/),
  он сам получает сертификаты для вашего домена.

После изменения `.env` перезапустите сервис: `docker compose up -d`.

## Панель модератора

Если задан `ADMIN_KEY`, панель доступна по адресу `/admin`: вход по этому ключу. В ней жалобы, скрытые и все приглашения,
пользователи (просмотр профиля, исправление данных, блокировка на срок или навсегда), журнал действий и показатели.
Пока `ADMIN_KEY` пуст, панель выключена
